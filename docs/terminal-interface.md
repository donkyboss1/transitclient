## Карта переходов

```text
Главное меню
├─ 1 Установка → мастер → план [y/N] → результат → Enter
├─ 2 Настройки
│  ├─ 1 HTTP-порт для сертификата → прежнее → новое → подтверждение
│  ├─ 2 Порт для проксирования трафика → прежнее → новое → подтверждение
│  ├─ 3 Локальный HTTPS-порт веб-сервера → прежнее → новое → подтверждение
│  └─ 4 Docker-сеть → подтверждение
├─ 3 Статус / 4 Диагностика → вывод с прокруткой под сводкой → Enter
├─ 5 Самопроверка
│  ├─ 1 Локальная HTTPS — чтение и TLS-проверка
│  ├─ 2 HTTP через релей — временный слушатель/firewall с очисткой
│  └─ 3 Из контейнера ноды — чтение и TLS-проверка
├─ 6 Сайты → 1–11 / r случайный / i встроенный / b откат
└─ 7 Инструкция / 8 Продление / 9 Обновление / 10 Удаление
   → результат → Enter
```

В каждом подменю `0` и Ctrl+C возвращают на один уровень. Прерывание ввода
настройки возвращает на уровень выше её подменю. Главное `0` и Ctrl+C завершают
интерфейс. EOF завершает интерфейс также из формы, подтверждения или паузы.
Навигация использует один цикл и стек экранов. Пустой/неизвестный пункт ничего
не выполняет; ошибка показывается на том же экране.

Во время действия Ctrl+C/EOF проходят через существующие finally/rollback.
После Ctrl+C выводится «Действие отменено», операция не продолжается.
Обычный отказ от подтверждения не записывается как авария.
Установка по Enter в `[y/N]` отменяется до применения изменений.

## Правила верхней панели

Панель читает локальные файлы и делает ограниченные запросы к локальному Docker
и systemd. Команды делят бюджет 2 секунды, одна команда — не более 0,4 секунды.
Недоступные сведения показываются как неизвестные. Полная диагностика,
ACME, recovery, firewall, загрузки и TLS-подключение при открытии меню не запускаются.
Docker daemon используется только после подтверждения локального Unix endpoint;
проверяются метки владельца и сервиса собственного Caddy.

`config.json` без Compose/сертификата и незавершённые журналы означают
незавершённую установку. Running, stopped, restarting, отсутствие контейнера
и неизвестное состояние различаются. SSL отсутствующий, повреждённый,
просроченный и истекающий в ближайшие 14 дней обозначаются отдельно.
«Действителен на диске» не подтверждает применение сертификата.

Последняя явная локальная проверка HTTPS хранится только в памяти текущего меню.
Результат связан с доменом, target, Docker-сетью и SHA256 файла цепочки сертификата и считается
актуальным 5 минут; показывается возраст. История операций не служит доказательством
текущего HTTPS. Слушатель VPN-порта не доказывает исправность REALITY.

Для очистки видимой области в обычном TTY используются `ESC[2J` и `ESC[H`.
Scrollback, альтернативный экран и сброс терминала не применяются.
Сводка одинакова на всех уровнях меню и экранах операций. Во время операции
область прокрутки ограничена строками под сводкой (`DECSTBM`), чтобы длинный
отчёт не вытеснял её с экрана. После Enter, Ctrl+C, EOF или исключения
восстанавливается полная область прокрутки. На экранах меньше 18 строк
применяется прежняя сокращённая сводка; на 48×20 все семь строк сохраняются.
`--no-color`/`NO_COLOR` убирают цвета; `TERM=dumb` и перенаправленный stdout
отключают все управляющие последовательности. CLI-команды сохраняют
последовательный вывод; прежние `--template 0/builtin/random/rollback/1–11`
сохраняют значение. В меню сайтов `0` означает только возврат.

## Условия приёмки и тесты

| Область | Приёмка | Проверка |
|---|---|---|
| Навигация | 0/Ctrl+C возвращают ровно на уровень; EOF завершает | unit + controlling PTY |
| Ввод | Пустой/неверный пункт остаётся на экране, без dispatch | unit + PTY |
| Результаты | Успех/ошибка сохраняются до Enter; до Enter нет очистки | PTY |
| Отмена | Сначала cleanup/rollback, затем выход из операции | реальные offline lifecycle unit + PTY |
| Установка | `[y/N]` + Enter отменяет; первая заглушка random без вопроса | существующие unit + PTY |
| Сайты | 11 вариантов, random/builtin/rollback; просмотр без изменений | unit + PTY |
| Настройки | Понятные назначения трёх портов; Docker-сеть прямо в пункте 4, старое → новое | unit + PTY |
| Панель | Состояния установки/Docker/SSL/timer, бюджет и запрет мутаций | unit, моки subprocess |
| Оформление | Caddy вместо hostname/ОС; подписи/заголовки/номера жирные, домен голубой, значения нейтральные, ровно один пробел после эмодзи | unit + визуальный preview |
| Общая сводка | Семь строк на всех экранах и во время длинных операций, возврат области прокрутки после Enter/Ctrl+C/EOF | unit + PTY |
| Обновление | После успешного применения показана команда `transitclient`; при отмене/ошибке успех не обещается | offline lifecycle unit |
| Ширина значков | На TTY символ шириной две клетки и курсором шириной одна/две даёт одну пустую клетку до текста; в данных один ASCII-пробел | независимая VT-модель + PTY |
| Режим установки | 1/2/0 вертикально, заголовок и номера жирные; Enter выбирает прежний режим 1 | unit + PTY |
| Повтор установки | Первая диагностика использует сохранённые порты и install_id; свой Caddy не показывает ложный конфликт, чужой listener блокирует | real diagnostic inventory с mocked CLI |
| Нумерация | Действия 1–10 идут по порядку на широком и узком экране; выбор совпадает с подписью | unit + PTY |
| TLS | Отсутствие/успех/ошибка/устаревание кеша, смена identity | unit |
| Размеры | 80×40 и 48×20, все номера и корректная ширина строк | unit + PTY |
| Терминал | Очистка без scrollback, dumb/NO_COLOR/no-color/redirect | unit + PTY |
| Циклы | 150 переходов через подменю без роста глубины стека | unit |
| Пакет | Новые runtime-модули в архиве; неполный 1.4.0 отклоняется | bootstrap/release unit |

Команды из корня проекта:

```powershell
uv run --with pytest --with cryptography python -m pytest tests -q --basetemp .cache/acceptance-tests
ruff check .
wsl -d Ubuntu -- bash -n /mnt/h/Dev/transitclient/install.sh
wsl -d Ubuntu -- python3 /mnt/h/Dev/transitclient/tests/pty_menu_check.py
```

PTY harness использует настоящий controlling terminal и клавиатурные Ctrl+C/Ctrl+D.
Операции подменены; audit hook запрещает запуск subprocess и сетевые запросы.
Состояния incomplete/Docker в PTY задаются фикстурами; реальная модель этих
состояний проверяется unit-тестами. Реальные установки и выпуск сертификатов
не выполняются. Этот прогон не подтверждает боевой HTTPS или работу ACME на сервере.

# Происхождение и лицензии

Каталог сайтов-заглушек использует `sni-templates` из фиксированного коммита
`24134e23a438217cd52373ecdb0fcf7983e0e72c` DigneZzZ/remnawave-scripts.
Исходная коллекция создана SmallPoppa; авторские уведомления и описание сохранены
в `vendor/templates-README.md`. HTML/CSS/JS и изображения скачиваются отдельно
из upstream по хешам `templates.json` и не исполняются на сервере установщиком.
Уведомления библиотек внутри исходных JavaScript-файлов не удаляются.

Этот пакет адаптирует установочный сценарий Selfsteal 2.10.0:
автор **DigneZzZ**, проект **gig.ovh**, [upstream](https://github.com/DigneZzZ/remnawave-scripts).
Оригинальные авторские уведомления и разрешение MIT сохранены в `LICENSE` и
`vendor/selfsteal-LICENSE`. Оригинальный локальный `selfsteal.sh` не изменён.
Компактная адаптация оставляет Caddy через Docker Compose, простой сайт,
резервные копии и команды обслуживания. В 1.1.0 добавлены preflight, transitclient,
три отдельных порта, безопасный bootstrap и выбранная Docker bridge-сеть.
Установочные ветки Nginx/QUIC исключены; в 1.2.0 добавлен каталог из 11 сайтов.
Фрагменты интеграции
с существующим веб-сервером поставляются только как ручная инструкция.

`vendor/acme.sh` — неизменённый исходный файл **acmesh-official/acme.sh 3.1.6**,
с исходными уведомлениями. Он распространяется отдельно по **GNU GPL v3**;
полный текст находится в `vendor/acme-LICENSE.md`. Этот файл исполняется как
самостоятельная программа через командную строку, а не включается в код MIT.
Архив представляет собой набор отдельных программ с разными лицензиями;
лицензия MIT собственных файлов не отменяет GPL для acme.sh. Полный исходный
файл поставляется в архиве, изменения acme.sh не вносились.

Caddy 2.11.4 и Docker Compose v5.6.0 лицензированы по Apache 2.0;
тексты находятся в `vendor/caddy-LICENSE` и `vendor/compose-LICENSE`.
Образ Caddy загружается из официального Docker Hub по digest, бинарный
Compose — из официального GitHub release по SHA256. Их исходники:
[Caddy v2.11.4](https://github.com/caddyserver/caddy/tree/v2.11.4),
[Compose v5.6.0](https://github.com/docker/compose/tree/v5.6.0).
Системные Ubuntu-пакеты устанавливаются средствами дистрибутива, с его
лицензиями/обновлениями; они не включены в экспортируемый архив.

Версии и хеши сверены 09.10.2026 по официальным upstream. `dependencies.json`
содержит проверенные SHA256 неизменённого acme.sh, релизных Compose-артефактов
(GitHub API `digest`) и digest OCI manifest list Caddy из официального registry.
`vendor/SHA256SUMS` фиксирует также тексты лицензий. Это проверка целостности
артефактов при повторной загрузке, а не заявление независимого аудита кода.

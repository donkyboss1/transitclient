# 🚀 Transit Client

Установщик для клиентов «Транзита»: настраивает локальный HTTPS-сайт,
получает сертификат для вашего домена и автоматически продлевает его.
Сертификат и приватный ключ остаются на вашем сервере.

## Установка

Запустите в SSH-терминале от root. Если вошли обычным пользователем,
сначала выполните `sudo -i`.

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/donkyboss1/transitclient/main/install.sh) install
```

Мастер проверит сервер, предложит настройки и покажет план перед установкой.
Вопросы подтверждения используют `[y/N]`; Enter отменяет действие.
Существующие сайты, службы и чужие контейнеры автоматически не меняются.
Команда передаёт скрипт Bash через файловый дескриптор, сохраняя терминальный
ввод для мастера. Установщик проверяет SHA256 и версию пакета перед запуском.

## Что понадобится

- Ubuntu 22.04, 24.04 или 26.04 с systemd, доступом sudo и Python 3.10 или новее.
- Доступ в интернет для загрузки компонентов и получения сертификата.
- Домен и HTTP-проверка, подготовленные в боте «Транзита».
- Свободный проверочный HTTP-порт (обычно 8080), совпадающий с указанным в боте
  и доступный через внешний firewall/NAT.

Сайт работает через Caddy в Docker Compose. Если Docker отсутствует,
мастер предложит его установить после подтверждения.

Мастер подготовит UFW: сохранит доступ к SSH и работающим службам,
сделает резервную копию и покажет изменения перед включением.
Проверочный порт открывается на время выпуска и продления сертификата.
Правила firewall в панели провайдера настраиваются отдельно.

## Управление

После установки откройте интерактивное меню:

```bash
sudo transitclient
```

Меню открывает каждый экран на том же месте, сохраняя историю прокрутки.
Действия пронумерованы по порядку от 1 до 9; заголовки и номера выделены
жирным, домен — голубым. Сводка показывает Caddy, порты, SSL, HTTPS,
автоматическое продление и выбранную заглушку. Эта сводка остаётся сверху
во всех подменю и во время действий; длинный вывод прокручивается под ней.
В настройках доступны порты для сертификата, проксирования трафика,
локального HTTPS веб-сервера и Docker-сеть.
`0` возвращает назад, в главном меню — выходит. `Ctrl+C` отменяет текущий экран;
результаты действий остаются видимыми до Enter. На узком экране меню компактное.
Для отключения цветов используйте `--no-color` или переменную `NO_COLOR`.
Верхняя сводка не запускает продление: HTTPS подтверждается явной самопроверкой.

Состояние установки всегда видно в верхней сводке; отдельного пункта статуса
в меню нет. «Диагностика» (3) проверяет сервер, выбранные порты, DNS и локальную
HTTPS; показывает результаты и обнаруженные проблемы. В конце нажмите `1`,
чтобы открыть подробный технический отчёт, или Enter, чтобы вернуться.
После подробного отчёта Enter возвращает в главное меню.

Основные действия доступны и отдельными командами:

```bash
sudo transitclient status       # состояние и срок сертификата
sudo transitclient diagnose     # диагностика сервера и портов
sudo transitclient diagnose --full  # подробный технический отчёт
sudo transitclient configure    # изменение настроек
sudo transitclient template     # выбор и смена сайта-заглушки
sudo transitclient renew        # проверка необходимости продления
sudo transitclient uninstall    # удаление с подтверждением
```

Если порт занят, выберите другой в мастере; для HTTP-проверки также измените
порт в боте. Если веб-сервер уже установлен, мастер покажет возможные конфликты
и предложит отдельный экземпляр Caddy или [инструкцию интеграции](docs/integration.md).

При установке автоматически выбирается и скачивается случайный сайт-заглушка.
После установки доступны 11 сайтов и простая встроенная страница. Сайт можно сменить
через меню; прежние файлы сохраняются для отката.

При удалении настройки, сертификаты, ключи, ACME account и сайт сохраняются
в отдельном закрытом каталоге с датой и временем. Повторная установка использует
версию загруженного установщика; прежние резервные копии остаются на месте.

Подробнее: [обслуживание и восстановление](docs/operations.md).
